# Sumava
This dataset supports the article "Linking Carbon-to-Nitrogen Resource Ratios to Nitrification and Nitrogen Leaching in Nitrogen-saturated Spruce Forest Soils", published in Ecosystems.
# Data and abbreviations
All data are in the file "Data_Sumava2008-2025.csv", and the variable descriptions, including units, are in "Data_Sumava2008-2025_abbreviations.csv". Most of the continuous variables are in micromoles per gram of dry soil. The micromoles are specified as "\mumol" in the list of abbreviations.
